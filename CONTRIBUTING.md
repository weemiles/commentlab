# Contributing

Run npm ci, npm run setup, npm test and npm run build using Node.js 22.16+ or current LTS. Use synthetic fixtures. Live API checks must use your own keys.

Preserve comment IDs, parent links and ambiguous/missing reference markers. Test insults versus quoted insults, sarcasm versus friendly laughter and constructive disagreement. Never infer hostility from usernames or political affiliation alone.

Do not weaken hosted authentication or add maintainer credentials/URLs as defaults. Keep secrets out of bundles, commits and issues. Describe behavior changes and validation in pull requests.
